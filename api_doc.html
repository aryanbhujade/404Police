404 Police API

Documentation and Endpoints

This documentation outlines the available API endpoints for the 404 Police service status dashboard. Each endpoint returns JSON data on the status of various services.

Endpoints

1. Get All Service Statuses

This is the group endpoint that gathers and returns the current status for every tracked service in a single JSON response. It’s the primary API call for summarising all services at once on the main dashboard.

Method: GET

URL: /api/status/all

Returns: A combined JSON object aggregating the individual JSON responses from each service's summary endpoint.

Status Code: 200 OK

2. Get Individual Service Status

This endpoint targets a specific service and proxies its status page by fetching from that service’s own summary.json API — for example, OpenAI’s at https://status.openai.com/api/v2/summary.json or Reddit’s at https://www.redditstatus.com/api/v2/summary.json. The JSON structure typically includes a top-level status description, a list of components with their operational state, and recent incident history. Our implementation uses this structure directly to power individual service cards with detailed live data.

Method: GET

URL Format: /api/<serviceName>

Example: /api/openai

Returns: JSON object with the status of the specified service
